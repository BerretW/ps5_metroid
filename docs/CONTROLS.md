# Controls

| Action | Keyboard | Game controller |
| --- | --- | --- |
| Move | Left/Right arrows or A/D | Left stick or D-pad |
| Jump / double jump | Space (configurable in Options) | A |
| Fire | J (configurable in Options) | X |
| Use door | E (configurable in Options) | Y |
| Pause / resume | Escape / Enter | Start |
| Toggle map | M | — |
| Menu navigation | Up/Down, Enter | D-pad, A |

Options can change volume and rebind jump, fire, and interact for the current run. Bindings are not persisted between launches yet. Controller support uses SDL's GameController API. The PS5 controller-only build is user-reported playable, but complete button mappings and reconnect behavior have not been separately verified. PS5 physical keyboard and IME support are disabled in that build; the on-screen hint bar still uses keyboard labels.
